# Rugby Direct SA

Rugby Direct SA is a Django-based e-commerce web application developed as a capstone project. The platform provides a modern online shopping experience for rugby players, coaches, clubs, and supporters looking to purchase rugby equipment, apparel, accessories, and training gear.

## Features

- User registration and authentication
- Product catalogue with images and descriptions
- Product search functionality
- Category-based product filtering
- Shopping cart management
- Quantity updating with automatic total calculation
- Cart persistence using Django sessions
- Checkout page
- Responsive mobile-friendly design
- Bootstrap-powered user interface

## Technologies Used

- Python
- Django
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- SQLite

## Learning Outcomes

This project demonstrates the implementation of full-stack web development concepts, including user authentication, session management, dynamic cart functionality, responsive user interface design, and database-driven web applications using the Django framework.
